## Blocking findings

### B1 — committed validation report is stale relative to the reviewed commit

`validation/validation-report.json` declares SHA-256

```text
WORK_PACKAGES.yaml = 7b4acdeda9a0bd51a0d1a747ccd162710dae3f812d6bf81673fd11d775ae1d45
```

The exact `WORK_PACKAGES.yaml` blob at the reviewed merge commit hashes to:

```text
0ce4406a94530a43a23bd62e2500e704d3ec0778cc34108f43920087128d556e
```

The current committed validator also emits `included_files` and `assembled_canonical_sha256`, but the committed report contains neither. Therefore the report was not generated by the exact committed validator over the exact reviewed tree.

A PASS report that does not attest the reviewed bytes cannot support acceptance.

### B2 — declared context packets do not exist

The DAG declares, among others:

```text
EpistemicCompilerLab/research-execution/context-packets/WP-001/TASK.md
EpistemicCompilerLab/research-execution/context-packets/WP-002/TASK.md
```

Both paths are absent at the reviewed commit.

This contradicts the program rule:

> Generate and hash before Backlog -> Todo.

`WP-001` is already in review, and `WP-002…WP-007` are actionable W0 tasks. Their missing context packets make the work packages non-executable under the adopted operating standard.

### B3 — required repository handoff is absent

The `WP-001` node declares:

```text
EpistemicCompilerLab/research-execution/handoffs/WP-001.json
```

The file is absent. A Linear prose comment is useful evidence but is not the declared schema-validated immutable handoff artifact.

### B4 — validator proves path shape, not artifact existence or integrity

For context packets the validator currently checks only that seven listed basenames equal the expected names. It does not verify:

- directories/files exist;
- `INPUT_MANIFEST.json` hashes resolve;
- `ACCEPTANCE.yaml` matches the node;
- forbidden/allowed paths are enforceable;
- `HANDOFF_SCHEMA.json` references the frozen schema;
- the handoff file exists and validates;
- acceptance commands have a declared working directory and are runnable.

Therefore `context_packet_executability: PASS` overstates what was tested.

### B5 — producer workflow deviation is unrecorded

Linear state history shows the package briefly transitioned to `Done` before returning to `In Review`. The operating standard says producer handoff goes to `In Review`, while `Done` requires independent review and gate PASS.

This corrected transition must be recorded in `protocol_deviations`; it cannot be silently treated as no deviation.

## Required revision

1. Generate and commit the complete `WP-001` context packet and schema-valid `handoffs/WP-001.json`.
2. Generate and hash context packets for every W0 issue already in `Todo`, or move those issues back to `Backlog` until packets exist.
3. Extend the validator to check context-packet and handoff existence, schema validity, manifest hashes and command working-directory contracts.
4. Add reviewed Git commit SHA, dirty-tree state and validator SHA to the report.
5. Regenerate `validation-report.json` from the exact final commit; all input hashes must match final repository bytes.
6. Record the premature `Done` transition as a protocol deviation in the immutable handoff.
7. Return to `In Review` only with a clean independent reproduction command whose execution does not require reconstructing missing artifacts.

## Decision
