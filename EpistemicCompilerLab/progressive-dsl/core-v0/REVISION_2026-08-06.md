## What changed in LogicLens

1. The former `CTO-course core` claim was removed. The artifact is now explicitly a domain-neutral **synthetic semantic kernel**.
2. Course-specific fixture IDs were removed from LogicLens.
3. Every evidence-bearing synthetic input now carries provenance and a dependency group.
4. Duplicate `premiseId`, `reportId`, evidence IDs and cross-stance evidence reuse fail closed.
5. Rational domains are separated into non-negative evidence, positive prior weight and a unit-interval decimal base rate.
6. Complete expected frames, cases, schema and runtime are SHA-256 frozen in `manifest-v0.json`.
7. Adversarial tests cover refutation, conflict, blocked logical bodies, malformed rationals, negative evidence, out-of-range base rates, missing provenance/dependency metadata, duplicate IDs and unit mismatch.
8. D2 compatibility uses `opinion-d2/runtime.py::build_frame()` and CI invokes SWI-Prolog; `compute()` alone is no longer accepted as independent evidence.
9. The launcher exposes `synthetic-kernel-tests`; the old action is only a compatibility alias.
